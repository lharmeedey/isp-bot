# SpeedNet ISP Telegram Bot

## Setup
1. Copy `.env.example` to `.env` and fill in your values
2. `npm install`
3. `node src/bot.js`

## Formatting
- Run `npm run format` to apply consistent JavaScript formatting across the source tree.
- Run `npm run format:check` to verify the codebase stays aligned.

## Commands
Customer: /start /register /balance /buy /history /support
Admin:    /sales /users /online /stock /revenue
